Tyk OAS Import API Documentation
The /tyk/apis/oas/import endpoint is part of Tyk's Gateway API and is used to import OpenAPI Specification (OAS) documents to create API definitions in Tyk.

Endpoint Details
URL: /tyk/apis/oas/import
Method: POST
Auth Required: Yes (Admin API Key)
Request Headers
X-Tyk-Authorization: Your Tyk Gateway API access token
Content-Type: application/json
Request Body
The request body should be a JSON object with the following structure:

{
  "oas": {
    // Your complete OAS document (JSON or YAML format)
  },
  "upstream_url": "https://your-upstream-api.com",
  "validate_request": true,
  "strip_listen_path": true,
  "enable_mock_response": false,
  "version_name": "v1"
}
Parameters:
oas (required): The complete OpenAPI Specification document
upstream_url (optional): The target URL for your API
validate_request (optional): Whether to validate requests against the OAS schema
strip_listen_path (optional): Whether to strip the listen path when forwarding requests
enable_mock_response (optional): Whether to enable mock responses based on examples in the OAS
version_name (optional): The version name for this API
Response
A successful response will return a 200 OK status code with a JSON body containing the created API definition:

{
  "key": "api_id",
  "status": "ok",
  "action": "added",
  "api_definition": {
    // The complete Tyk API definition
  }
}
Error Responses
400 Bad Request: Invalid OAS document or parameters
401 Unauthorized: Invalid or missing API key
500 Internal Server Error: Server-side error
Example Usage
curl -X POST \
  https://your-tyk-gateway/tyk/apis/oas/import \
  -H 'X-Tyk-Authorization: your-api-key' \
  -H 'Content-Type: application/json' \
  -d '{
    "oas": {
      "openapi": "3.0.0",
      "info": {
        "title": "Sample API",
        "version": "1.0.0"
      },
      "paths": {
        "/users": {
          "get": {
            "responses": {
              "200": {
                "description": "OK"
              }
            }
          }
        }
      }
    },
    "upstream_url": "https://api.example.com",
    "validate_request": true
  }'
For more detailed information, you might want to check the official Tyk documentation at https://tyk.io/docs/ or contact Tyk support if you need specific implementation details.
